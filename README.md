# Robot-GST

Static research project page built with HTML, CSS and JavaScript. No external runtime, fonts, analytics or video embeds.

## Preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Media

The paper overview is a locally hosted 1080p H.264/AAC MP4, optimized for progressive playback. It loads on demand.

Task demonstrations contain the full aligned sequences: cube (20 seconds), toy (24 seconds), and ducks (31 seconds). These files were temporally retimed for comparison; playback timing is not a measurement of original execution speed. The paired-play control starts both clips together and corrects drift. Individual video controls remain available.

The toy clip includes a failed real-world packing attempt. The final frame is marked accordingly. Figure 6 presents the revision and successful packing result. Table II reports task-level aggregate results, not the outcome of an individual displayed clip.

Figures can be opened at full resolution. Tables remain horizontally scrollable on narrow screens. Layout inspired by Real2Sim-Eval.
